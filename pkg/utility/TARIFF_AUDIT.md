# Electric Utility Tariff Audit Registry

This file is the authoritative tariff audit registry for all visible electric utility providers in `pkg/utility` (`!u.Hidden && u.ID != "tou_example"` in `utility.NewMap(nil).ListUtilities()`).

## Maintenance & Audit Guidelines

1. **Authoritative Official Sources Only:** Verify all volumetric rates, riders, TOU windows, holiday calendars, and solar/battery export credits exclusively against official utility tariff books, state PUC/PSC dockets, ISO/RTO market feeds, official government comparison portals (e.g., PUCT Power to Choose, AER Energy Made Easy, Victorian Energy Compare), or official provider APIs. Never link or rely on unverified third-party tariff aggregators or blogs.
2. **Keep Registry & Source Headers in Sync:** Contributors and automated runs must update the corresponding row(s) in the table below (`Repo Effective Horizon`, `Next Audit Due`, `Last Verified`, `Official Source URL(s)`, and `Notes`) during PR review whenever existing rate schedules or riders change in `pkg/utility/*.go`, or when adding a provider. `TestListUtilities/TariffAuditRegistryCoversAllUtilities` in `pkg/utility/utility_test.go` enforces visible provider and exact rate-plan ID coverage plus required column formatting, whereas horizon, verification-date, URL, and note updates on existing schedules must be verified during PR review.
3. **Preserve Historical Determinism:** Never overwrite past effective periods needed by `GetConfirmedPrices`, `TestPlanHistory`, or `TestControllerHistory`. End-date superseded periods at their transition timestamp and append new effective periods.
4. **Standard Per-File `Tariff Audit Metadata` Comment Header Template:** When creating or updating `pkg/utility/<utility>.go` (or an inline provider block in `pkg/utility/tou.go`), maintain this standardized comment header at the top of the file/block:

```go
// Tariff Audit Metadata
// - Provider(s): <provider_id> (<Utility Display Name>)
// - Official Sources:
//   - <Direct URL to official rate schedule / tariff book / PUC docket page>
//   - <Exact Schedule / Sheet / Rider / Docket / Supplement numbers>
// - Effective Window: <YYYY-MM-DD> through <YYYY-MM-DD or "until superseded">
// - Revision Cadence: <Monthly | Quarterly (e.g., Mar/Jun/Sep/Dec 1) | Semi-Annual (Mar 1 & Sep 1) | Annual (e.g., Jun 1)>
// - Next Audit Due: <YYYY-MM-DD> (<specific upcoming filing/rider to check next>)
// - Last Verified: <YYYY-MM-DD>
// - Modeling Notes: <Tier 1 volumetric assumption, excluded fixed $/mo fees, net-metering/export rules>
```
