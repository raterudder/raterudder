How to Connect

  1. Copy the MCP server URL above.
  2. Add it as a custom connector or remote MCP server in an MCP-compatible AI assistant (such as Claude or ChatGPT).
  3. Sign in to RateRudder and approve read-only access to your site when prompted.

If your assistant requires a static Bearer API key instead of OAuth, you can create one under Settings → Connected Apps.
